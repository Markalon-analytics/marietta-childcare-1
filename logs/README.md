# logs

## Why this folder exists
Execution, decision, error, and process-optimization logs live here.

## What types of files live here
Markdown control files, logs, templates, QA records, or project-specific artifacts named by purpose.

## When should an agent read from or write to this folder?
Read when the current task touches this folder's scope. Write only when updating that scope's canonical artifact.

## How this folder connects to the rest of the project
This folder supports `MASTER_PLAN.md`, `MASTER_TODO.md`, `MEMORY_LOG.md`, and `context/CURRENT_STATE.md`.
