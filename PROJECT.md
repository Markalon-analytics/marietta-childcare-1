# Marietta Childcare URL and Canonical Audit

## Original request

Audit the entire site and sitemap for the missing hyphen in sitemap URLs and for canonical URL configuration; list findings in a Markdown file and make the appropriate changes.

## Deliverable contract

- `REQ-URL-01`: Identify and correct the sitemap URL path issue, including the hyphenated `/service-areas/` route.
- `REQ-CAN-01`: Audit every generated HTML page for one correct absolute canonical URL matching the intended public route.
- `REQ-REPORT-01`: Add a Markdown audit report documenting scope, denominator, findings, changes, exceptions, and verification evidence.

## Definition of done

The source has one canonical URL strategy, generated sitemap URLs use existing public routes, every generated HTML page has exactly one correct absolute canonical, and the report is backed by a fresh production build plus inventory-level checks.

## Coverage

The denominator is the complete set of HTML pages generated by `npm run build`, plus every URL emitted by the generated sitemap index/child sitemap files and every page route declared in `src/pages`. Each generated page receives a leaf-level canonical check; each sitemap URL receives a route existence and canonical consistency check.

## Substantive QA and evidence

- Build output is the source of truth for emitted routes, canonical tags, and sitemap XML.
- Source review covers `astro.config.mjs`, `src/components/SeoHead.astro`, every file under `src/pages`, route data in `src/data/site.ts`, and `public/robots.txt`.
- The audit report records item-level results and any exceptions rather than relying on aggregate counts alone.

## Scope and non-goals

In scope: Astro route generation, sitemap integration/configuration, canonical generation, robots sitemap reference, and the requested audit report. Out of scope: external BBMA URLs, search-engine submission, DNS, deployment, or content/visual changes unrelated to URL identity.
