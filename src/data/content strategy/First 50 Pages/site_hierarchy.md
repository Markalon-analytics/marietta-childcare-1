## User Journey Flows

### Primary Conversion Flow
```
Home → Programs Overview → Specific Program → FAQ → Schedule Tour
```

### Parent Research Flow
```
Home → Resources/Parenting Tips → Program Pages → FAQ → Schedule Tour
```

### Local Search Flow
```
Home → Service Areas → Local Area Page → Programs → Schedule Tour
```

### Problem-Solution Flow
```
Home → Solutions → Use-Case Page → Program Page → Schedule Tour
```

## Page Depth & Hierarchy Levels

- **Level 1 (Root):** Home, About, Programs, Resources, Service Areas, Solutions, Contact, Blog
- **Level 2 (Category):** Program categories, resource types, local areas, use-cases
- **Level 3 (Detail):** Individual program pages, specific FAQ items, detailed use-case pages

## Internal Linking Strategy

- **Home** links to all Level 1 pages and featured programs
- **Programs Overview** links to all 10 program pages
- **Service Area Page** links to all 9 local area pages
- **Solutions Page** links to all 9 use-case pages
- **Each program page** links to related FAQ pages, resources, and use-cases
- **Each FAQ page** links to relevant program pages and resources
- **Each use-case page** links to relevant program pages and FAQ items
- **Resources pages** link to related program pages and FAQ items

## Conversion Path Optimization

- **High-intent pages** (Schedule Tour, Contact, Programs) are 2-3 clicks from home
- **Informational pages** (FAQ, Resources) support decision-making before conversion
- **Local pages** support geographic targeting and local SEO
- **Use-case pages** address specific parent situations and needs
- **Program pages** are primary conversion drivers with clear CTAs
